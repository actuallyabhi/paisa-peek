CSV format · download sample

Header row, any column order. Only amount is required.

date,type,amount,description,party,category,account,tags,notes
2026-01-24,expense,500,Pizzahut,,Food & Outings,,JAN 24-25 Outing,
,lent,3000 + 1800,Lent,Saurabh,,,,
2026-02-10,repaid_to_me,2000,Paid back via UPI,Saurabh,,HDFC xx1234,,
  • date: YYYY-MM-DD or DD/MM/YYYY. Blank uses the date above.
  • type: expense (default), income, transfer, lent, borrowed, repaid_to_me, repaid_by_me.
  • amount: 450, 1,23,456.50, or an Excel-style breakdown 720 + 775 + 380 (summed; the breakdown goes into notes).
  • party: person or company, created if new. Needed for lent / borrowed / repaid rows.
  • category, account: an existing name (account can also be its last 4 digits). Blank category is guessed.
  • tags: separated by ;
